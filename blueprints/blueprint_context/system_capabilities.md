# Existing System (SCA) Capabilities

- Resume vs JD matching (TF-IDF + cosine)
- Skill extraction (keyword + basic NER)
- Job role prediction (ML model)
- Domain fit prediction
- Salary prediction
- Resume enhancement using LLM
- Project recommendations
- Learning resources

## Limitations

- Hardcoded skill logic
- Weak semantic understanding
- No reasoning layer
- No unified intelligence system
- No skill graph or context awareness
- No explainability in outputs
