# NeuroSync Target System

We are NOT building tools.

We are building a Career Intelligence Engine.

## Core Requirements

- Semantic understanding (not keyword match)
- Skill graph-based reasoning
- Gap intelligence (priority + impact)
- Explainable outputs
- LLM-assisted reasoning
- Modular + scalable backend

## Output Expectations

System must provide:

- match_score
- semantic_score
- skill alignment
- gap reasoning
- actionable insights
- AI-powered suggestions

## Standard

System must be:

- production-grade
- scalable to millions of users
- clean architecture
- no hardcoded logic
